Loan Approval Prediction Using Machine Learning
About the Project

This is a minor project based on Supervised Machine Learning. The project uses applicant information to predict whether a loan application is likely to be approved or rejected.

Objective

The main objective is to analyze loan applicant data and build a Machine Learning model that predicts loan approval based on the available information.

Dataset

The dataset contains information about loan applicants. It is used to train and evaluate the Machine Learning model.
